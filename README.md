# Math Elements

数学記号をドラッグして、組み合わせ・分解・変形する数学と物理の実験室です。黒いワークスペース、数式そのものを使う操作、短い変換アニメーションで構成しています。React / TypeScript / Vite で動く、ローカル保存対応の完成プロトタイプです。

## 起動

Node.js 22.12 以上（開発時は 24）と npm を用意してください。

```sh
npm install
npm run dev
```

表示されたローカル URL（通常 `http://localhost:5173`）を開きます。アカウント、API キー、バックエンドは不要です。KaTeX のフォントもアプリと一緒に配信され、実行時の外部サービスへの通信はありません。

```sh
npm run build       # TypeScript strict 検査と本番ビルド
npm run preview     # dist のプレビュー
npm test            # Vitest の全テスト
npm run test:e2e     # Chromium で操作テスト
```

E2E テストを初めて実行する環境では、一度 `npx playwright install chromium` を実行してください。ブラウザが未導入でも通常の起動・ビルド・単体テストには影響しません。

## 遊び方

1. 下のトレイから記号をワークスペースへドラッグします。トレイは横にスクロールできます。
2. `+` を `2` に重ねると `2 + □` ができます。そこに `3` を重ねると `2 + 3` になります。
3. 式をダブルクリックすると `5` に簡約されます。選択パネルの「簡約する」も使えます。
4. 数や式を直接重ねると掛け算です。`2` と `x` は `2x`、`x` と `x` は `x²` になります。
5. 右クリックの「分解 / Break apart」で構成要素に戻せます。タッチ端末では選択パネルの「分解する」を使います。

互換性のある相手だけに吸着表示が出ます。無効な組み合わせやゼロ除算では、既存の要素を消しません。右上のフラスコから、すぐに操作できる実験を読み込めます。実験による配置の置き換えも Undo できます。

| 操作                         | 効果                                     |
| ---------------------------- | ---------------------------------------- |
| クリック / タップ            | 選択と詳細表示                           |
| ドラッグ                     | 移動 / 反応                              |
| ダブルクリック               | 評価・簡約                               |
| 右クリック                   | 簡約・分解・複製・削除                   |
| Delete / Backspace           | 選択要素を削除                           |
| Ctrl+Z / Cmd+Z               | Undo                                     |
| Ctrl+Shift+Z / Cmd+Shift+Z   | Redo                                     |
| Escape                       | 選択解除、ドラッグ取消、メニューを閉じる |
| Tab → トレイで Enter / Space | 記号を配置                               |
| 選択要素上で Enter           | 簡約                                     |

## 数学

### 括弧の中・式の一部分を操作

- `sin(2 + 3)` の `2` など、中身をクリックするとその部分が選択されます。選んだ部分をドラッグして外へ取り出せます。初めて触ったままドラッグしたときは式全体を動かすため、通常の移動で誤って分解しません。
- 小さい記号は、右の「中身を選ぶ」ボタンからも選択できます。「ひとつ外側へ」で括弧内の式全体を選び、「中身を分解する」で `2`・`+`・`3` に分けられます。
- 取り出した跡は `□` として残ります。別の数・式をそこへドロップすると戻せます。未完成の式も保存でき、取り出し・再挿入は Undo / Redo に対応します。
- 「この部分を簡約する」は外側を保持します。例えば `sin(2 + 3)` の中だけを簡約すると `sin(5)` です。
- ドラッグ中は吸着先と完成後の式をプレビューします。記号の中心だけでなく、表示の端や指の位置も使って判定し、タッチの許容範囲は広くしています。トレイはクリック / タップだけでも配置できます。

取り出し・差し替えは数式の編集です。方程式を同値変形して解くときは、引き続き「両辺に同じ操作」を使います。

### 対応する演算

- **四則演算・代数**：同類項の整理、数の係数、正の整数べきの結合、分解。小数の算術も有理数として計算します。
- **分数**：縦型表示。`1/2 + 1/3` は `3/6 + 2/6` を見せてから `5/6` に変わります。
- **方程式**：`=` で式をつなぎます。方程式を選ぶと、線形方程式を解く次の操作が出ます。`2x + 3 = 7` では両辺から `3` を引く途中式を表示し、その後、両辺を `2` で割れます。数を付けた `−` や `÷` を方程式に重ねる操作にも対応します。
- **指数**：右上の指数自体を選択・編集できます。`x³` の分解は `x × x × x` です。
- **関数**：sin、cos、tan、log（底10）、ln、exp、平方根。三角関数の角度はラジアンです。既知の厳密値を簡約し、π・e や一般の関数は記号として保持します。近似値は選択パネルから別表示できます。
- **微分**：独立した `d/dx` 要素を式に重ねます。べき乗則、和・積・商・合成関数の規則、sin / cos / tan / log / ln / exp、`e^x` に対応します。
- **積分**：`∫ dx` を重ねます。単項式、多項式、定数倍、sin / cos / exp、`e^x` などの対応範囲では原始関数に必ず `+ C` を付けます。

## ベクトル・行列

「ベクトル・行列」トレイから矢印や 2×2 行列を配置できます。

- 矢印の線をドラッグすると平行移動、選択後の端点ドラッグでは長さと方向が変わります。端点操作は 0.25 単位に吸着します。
- 一方の始点を別の終点へ重ねると合成ベクトルになります。元の成分ベクトルを破線で残します。選択時に成分・大きさ・角度を確認できます。
- 行列の各セルは選択パネルから編集できます。グリッドボタンで座標空間を表示し、そこに行列をドロップすると変換が動きます。「グリッドに適用」なら行列要素を残して試せます。
- 行列とベクトルを重ねると、行列×ベクトルの結果ができます。

## Physics

Math / Physics で独立したワークスペースを切り替えます。

- `m` をドラッグして物体を配置します。選択すると質量・初速・角度・重力・力の各成分を編集できます。
- force / velocity / acceleration / gravity を物体に重ねて適用します。力はベクトル加算し、`a = F / m` で計算します。
- Run / Pause / Reset でシミュレーションを操作します。設定変更はシミュレーションをリセットします。再投射するときは Reset → Run を使います。
- 初速 `20 m/s`、角度 `45°`、重力 `9.81 m/s²` なら斜方投射になります。力が一定の場合の運動方程式を解析的に評価し、フレームレートに依存する積分誤差を避けます。
- `x(t)`・`y(t)` は発射点を原点として右・上を正にした変位、`vx`・`vy` は速度成分です。高い位置からの落下にも対応し、床との交点で投射を停止します。
- 地面上の物体では下向きの力を床が支え、水平には摩擦なしで加速できます。
- 軌跡の ON/OFF、time の時計、distance のものさしを使用できます。物理空間では 10 px が 1 m です。

## Challenges と保存

加算、簡約、方程式、分数、微分、積分、ベクトル合成、斜方投射の **10 問**を実装しています。答えの入力欄はなく、ワークスペースの操作で達成します。判定は AST または実際の運動結果を使います。

Math / Physics の Sandbox、設定、チュートリアル完了状態、達成したチャレンジを `localStorage` の `math-elements:v1` に保存します。再読込時に Sandbox を復元します。破損データは検証して安全な初期値に戻し、保存できない環境でもアプリ自体は動作します。Undo / Redo の履歴と進行中のシミュレーションはセッション内のみです。

## 技術構成と検証

- React 19、TypeScript strict、Vite 6、Tailwind CSS 4、Zustand 5、KaTeX。
- DOM + Pointer Events によるマウス・タッチ操作、SVG によるベクトル・行列グリッド・軌跡、Web Audio によるミュート可能な効果音。
- 数式は判別可能な AST。JavaScript `eval()` や数式文字列の実行は使いません。
- Vitest：AST、演算、同類項、分数、定義域、方程式、微積分、ベクトル、行列、運動、履歴、保存、チャレンジ判定。
- Playwright：全 10 問の実操作、ドラッグのオフセット、取消、ゼロ除算、指数選択、端点編集、行列グリッド、力の適用、保存復元、破損保存、タッチ、1280×720 とモバイル画面。

設計と拡張方法は [ARCHITECTURE.md](./ARCHITECTURE.md) を参照してください。

## プロトタイプの範囲

- 実数を対象とした規則ベースの記号計算です。汎用 CAS、複素数、任意の方程式の自動求解は対象外です。未知の定義域に依存する約分は行いません。
- 未対応の積分（例：`sin(x²)`、絶対値が必要な `1/x`）は、正しい積分記号のまま保持します。微分も未対応の形は形式的な微分として残します。
- 安全な整数の範囲を超える有理数の結果は、元の式を保持します。近似表示と物理計算は浮動小数点です。
- 行列は実数 2×2、ベクトルは 2D。物理は一定の外力と一様重力、平らな床を扱い、物体同士の衝突・空気抵抗・反発は含みません。
- PC 1280×720 以上を中心に設計しています。タブレットの基本操作とモバイル表示に対応しますが、画面外まで伸びる大きな式・ベクトル用の無限パン・ズームはありません。
